# GPT Text Generator

## Project Overview
This project generates meaningful text from a user prompt using the pre-trained DistilGPT2 model from the Hugging Face Transformers library.

## Technologies Used
- Python
- Transformers
- DistilGPT2
- Gradio
- GitHub Codespaces

## Features
- User prompt input
- AI-generated text output
- Interactive web interface
- Pre-trained GPT model

## Example

Input:
Artificial Intelligence is transforming education because

Output:
Artificial Intelligence is transforming education because it enables personalized learning and improves accessibility to education.

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
